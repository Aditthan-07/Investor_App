# 🧠 FinSight AI – ML-Powered Financial Assistant

FinSight AI is an intelligent financial assistant built using **Streamlit**, **Machine Learning**, and **Financial Data APIs** to simplify investment decisions and financial health tracking.  
It analyzes **market trends**, **user financial data**, and **news sentiment** to provide actionable insights and personalized recommendations for Indian investors.

---

## 🚀 Features

- 📊 **Stock Market Dashboard**  
  View real-time stock prices and trends from Yahoo Finance (NIFTY 50 and major Indian companies).

- 💬 **News Sentiment Analysis**  
  Uses **TextBlob** to analyze financial news headlines and calculate a sentiment score (Positive / Negative / Neutral).

- 🤖 **Investment Recommendation Model**  
  Predicts whether a user should **Invest**, **Hold**, or **Avoid** based on their salary, credit score, loan status, and risk level using a **Random Forest Classifier**.

- 💰 **Financial Health Scoring System**  
  Evaluates user’s financial stability and categorizes it as *Poor*, *Fair*, or *Good*.

- 📈 **Interactive Visualizations**  
  Built with **Plotly** for dynamic line charts and bar graphs showing market performance and investment risk insights.

- 🌐 **Streamlit Web App**  
  A clean and responsive UI for real-time interaction with all the features.
